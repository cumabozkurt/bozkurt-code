Quick startHızlı başlangıç

From zero to https://shop.test in six commandsAltı komutla sıfırdan https://shop.test'e

Admin rights are needed only for OS DNS routing and, optionally, system-store trust. Each is one named step you confirm. Everything else runs as your user. The desktop app does the same through Overview → Quick setup.Yönetici izni yalnızca işletim sistemi DNS yönlendirmesi ve isteğe bağlı olarak sistem deposuna güven için gerekir. Her biri onayladığın, adı belli tek bir adımdır. Geri kalan her şey senin kullanıcınla çalışır. Masaüstü uygulaması aynısını Genel bakış → Hızlı kurulum ile yapar.

~/code/shop
$ bz doctor              # ports, DNS, trust, PATH
$ bz dns setup           # route *.test (admin prompt)
$ bz trust               # trust the local CA
$ bz php install 8.3     # or: bz node install 22
$ bz link --https
$ bz open                # → https://shop.test

Architecture & securityMimari ve güvenlik

Local-first, locked down by defaultÖnce yerel, varsayılan olarak kilitli

Rust coreRust çekirdek

bz-core (runtimes, services, sites, supervisor, detection, Caddyfile) and bz-net (DNS, local CA, trust, ports) behind an axum HTTP API with WebSocket events.bz-core (ortamlar, servisler, siteler, denetleyici, algılama, Caddyfile) ve bz-net (DNS, yerel CA, güven, portlar); WebSocket olaylı bir axum HTTP API'sinin arkasında.

Hardened local APISıkılaştırılmış yerel API

Per-install token, Origin and Host checks against CSRF and DNS rebinding, JSON-only writes. Sites bind to loopback unless you enable lan_access.Kuruluma özel anahtar, CSRF ve DNS rebinding'e karşı Origin ve Host denetimi, yalnızca JSON yazma istekleri. lan_access açılmadıkça siteler yalnızca loopback'e bağlanır.

Verified downloadsDoğrulanmış indirmeler

Published checksums are enforced. Assets without one are refused unless you opt in once, after which their SHA-256 is pinned (trust on first use).Yayınlanmış sağlama toplamları zorunludur. Sağlama toplamı olmayan dosyalar, bir kez açıkça izin vermedikçe reddedilir; ardından SHA-256 değerleri sabitlenir (ilk kullanımda güven).
